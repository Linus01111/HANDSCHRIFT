# Handschrift-Generator

Zeichne deine Handschrift mit dem Apple Pencil und mach aus beliebigem Text
GoodNotes-Dateien mit radierbarer Tinte (oder Vektor-PDFs).

- Läuft komplett im Browser, nichts wird hochgeladen. Deine Zeichen bleiben im Browser des Geräts; mit „Handschrift sichern“ bekommst du eine Datei zum Umziehen.
- Der GoodNotes-Export nutzt [goodnotes-codec](https://github.com/Taylor-Nilsen/goodnotes-codec) (MIT, `LICENSE-goodnotes-codec.txt`) über Pyodide. Das Format ist inoffiziell nachgebaut und nicht von GoodNotes.
